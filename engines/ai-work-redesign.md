# AI Work Redesign Engine

## Purpose

重新设计“工作”，而不是先判断“哪些岗位会被 AI 替代”。

## Workflow

```text
Outcome
 ↓
Work
 ↓
Tasks
 ↓
Decision / Execution / Relationship / Accountability
 ↓
Human / AI / Agent allocation
 ↓
Role redesign
 ↓
Authority redesign
 ↓
Metric redesign
```

## Task Classification

### Human-first

需要最终责任、复杂关系、价值判断、现场操作、不可委托的决策。

### AI-first

结构化分析、分类、预测、生成、转换、检索、模式识别等适合模型处理的任务。

### Agent-first

可以被明确目标、工具、权限和边界驱动，持续执行的多步骤工作流。

### Hybrid

由 AI/Agent 处理信息和执行，人负责判断、授权、例外处理和最终责任。

## Required Questions

1. 这个工作最终对哪个业务结果负责？
2. 工作由哪些任务组成？
3. 哪些任务需要人类判断？
4. 哪些任务可以自动化？
5. 哪些任务适合 Agent 持续执行？
6. Agent 需要什么工具和权限？
7. 谁拥有最终 accountability？
8. 旧岗位哪些职责应删除、增加或重组？
9. KPI 是否仍然衡量正确结果？
10. 如何验证重构真的提高了生产率、质量或速度？

## Guardrail

不要用“AI 能做这件事”直接推出“这个岗位应该消失”。岗位是任务组合；任务组合变化后，岗位边界、责任、权限和管理跨度都可能重新定义。
