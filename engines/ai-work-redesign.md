# AI Work Redesign Engine / AI 工作重构引擎

## Purpose / 目的

Redesign **work**, rather than starting with “which jobs will AI replace?”.

重构的是**工作**，而不是先判断“哪些岗位会被 AI 替代”。

## Workflow / 工作流

```text
Outcome / 结果
 ↓
Work / 工作
 ↓
Tasks / 任务
 ↓
Decision | Execution | Relationship | Accountability
判断 | 执行 | 关系 | 责任
 ↓
Human | AI | Agent allocation / 人-AI-Agent 分工
 ↓
Role redesign / 岗位重构
 ↓
Authority redesign / 权限重构
 ↓
Metric redesign / 指标重构
```

## Task Classification / 任务分类

### Human-first / 人优先

Final accountability, complex relationships, value judgment, physical presence, or decisions that cannot be delegated.

最终责任、复杂关系、价值判断、现场操作，或不可委托的决策。

### AI-first / AI 优先

Structured analysis, classification, prediction, generation, transformation, retrieval, and pattern recognition.

结构化分析、分类、预测、生成、转换、检索与模式识别。

### Agent-first / Agent 优先

Multi-step workflows that can be driven by explicit goals, tools, permissions, and boundaries.

可以由明确目标、工具、权限与边界持续驱动的多步骤工作流。

### Hybrid / 混合

AI/Agent handles information and routine execution; humans handle judgment, authorization, exceptions, and final accountability.

AI/Agent 处理信息与常规执行；人负责判断、授权、例外处理和最终责任。

## Required Questions / 必答问题

1. What business outcome does this work own? / 这项工作最终对哪个业务结果负责？
2. What tasks compose it? / 它由哪些任务组成？
3. Which tasks require human judgment? / 哪些任务需要人类判断？
4. Which tasks can be automated? / 哪些任务可以自动化？
5. Which tasks suit Agents? / 哪些任务适合 Agent 持续执行？
6. What tools and permissions does the Agent need? / Agent 需要什么工具与权限？
7. Who owns final accountability? / 谁拥有最终 accountability？
8. Which role responsibilities should be deleted, added, or recombined? / 旧岗位哪些职责应删除、增加或重组？
9. Do KPIs still measure the right outcome? / KPI 是否仍然衡量正确结果？
10. How will productivity, quality, speed, or cost be validated? / 如何验证生产率、质量、速度或成本真的改善？

## Guardrail / 护栏

“AI can do this task” does **not** imply “this job should disappear”. A role is a bundle of tasks; when the bundle changes, role boundaries, accountability, authority, and management span may all need redesign.

“AI 能做这件事”**不等于**“这个岗位应该消失”。岗位是任务组合；任务组合变化后，岗位边界、责任、权限和管理跨度都可能需要重新定义。
