# Case 10 — Agentic Operations / Agent 化运营

**Prompt / 场景**

A company wants agents to run customer operations end-to-end. Leadership asks what jobs can be eliminated.

**Expected agent behavior / 期望行为**

Map workflows, decisions, accountability, data access, action permissions, escalation, auditability and human override. Then identify work that can be automated, augmented, redesigned or newly created.

**Good-answer signature / 好答案特征**

The agent designs an operating model for humans and agents together, with explicit governance and measurable outcomes.
