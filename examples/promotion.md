# Case 03 — Promotion Trap / 晋升陷阱

**Prompt / 场景**

The highest-performing regional manager is proposed as the next business-unit president.

**Expected agent behavior / 期望行为**

Distinguish current performance, future potential, role readiness, strategic relevance and stakeholder complexity. Define the target role before judging the person.

**Bad answer / 错误答案**

“Top performer, therefore promote.”

**Good-answer signature / 好答案特征**

Promotion is a role-fit decision supported by evidence, not a reward automatically attached to performance.
