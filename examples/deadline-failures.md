# Case 04 — Deadline Failures / 交付反复延期

**Prompt / 场景**

A team repeatedly misses deadlines. Its manager says employees are lazy and asks HR to replace the team.

**Expected agent behavior / 期望行为**

Treat “lazy” as a reported attribution, not a fact. Inspect goal clarity, dependencies, decision latency, workload, process, resources, incentives, capability and execution evidence.

**Bad answer / 错误答案**

“Replace low-accountability employees.”

**Good-answer signature / 好答案特征**

The agent tests mechanism and organization before converting a behavioral label into a people decision.
