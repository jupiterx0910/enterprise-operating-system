# Example: Revenue Gap Diagnosis

> Illustrative example. Numbers are intentionally synthetic.

## User Problem

“Revenue is 18% below plan. Should we replace the sales leader?”

## Agent Response Pattern

### 1. Do not jump to REPLACE

The observed symptom is a revenue gap. A sales-leader problem is only one hypothesis.

### 2. Diagnose

| Dimension | Hypothesis |
|---|---|
| Strategy | target market or offer is misaligned |
| Organization | sales/product handoff is weak |
| Mechanism | incentives or territory design distort behavior |
| People | capability or leadership gap |
| Execution | pipeline discipline or cadence failure |

### 3. Evidence Needed

- pipeline coverage
- conversion by stage
- win/loss reasons
- lead quality
- pricing changes
- territory productivity
- rep ramp time
- sales-manager span
- incentive plan

### 4. Decision

Only after evidence supports a person-specific root cause should REPLACE become the leading intervention.

### 5. Action

Run a 30-day diagnostic sprint, fix the highest-confidence system constraint, and set a formal review date for the leadership decision.
