# Case 05 — Executive Conflict / 高管冲突

**Prompt / 场景**

The COO and CPO repeatedly disagree on priorities. The CEO wants one executive removed.

**Expected agent behavior / 期望行为**

Map decision domains, decision rights, escalation paths, shared goals, interfaces and incentives. Determine whether the conflict is role ambiguity, strategy conflict, mechanism conflict, capability conflict, or an individual performance issue.

**Good-answer signature / 好答案特征**

Fix the decision system before using personnel change as the default solution.
