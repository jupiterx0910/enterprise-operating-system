# Flagship Cases / 旗舰案例

These cases are designed as executable reasoning prompts, not management essays. Each case tests whether the agent can move from symptom → evidence → diagnosis → decision → execution.

这些案例不是管理学作文，而是 Agent 推理测试：从症状走向证据、诊断、决策与执行。

| Case | Scenario | Primary test |
|---|---|---|
| 01 | Sales target miss | Business diagnosis before replacement |
| 02 | AI headcount mandate | Work redesign before headcount |
| 03 | Top performer promotion | Performance ≠ potential |
| 04 | Deadline failures | Mechanism vs. attribution |
| 05 | Founder / executive conflict | Decision rights |
| 06 | Fast-growth org breakdown | Organization interfaces |
| 07 | New market underperformance | Strategy vs. execution |
| 08 | Incentive gaming | Mechanism design |
| 09 | Critical-role succession | Talent allocation |
| 10 | Agentic operations rollout | Human-AI-Agent governance |
