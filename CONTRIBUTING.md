# Contributing / 贡献指南

## What we want / 我们欢迎什么

This project improves when contributions make the Agent more accurate, evidence-aware, testable, and useful in real enterprise scenarios.

我们欢迎能让 Agent 更准确、更重证据、更可测试、更贴近真实企业经营的问题与贡献。

### High-value contributions / 高价值贡献

- Real business cases / 真实业务案例
- Adversarial prompts / 对抗性 Prompt
- Diagnostic improvements / 诊断逻辑改进
- Evidence and uncertainty standards / 证据与不确定性标准
- Human-AI-Agent workflow patterns / 人-AI-Agent 工作模式
- Evaluation cases and scoring criteria / 评测案例与评分标准
- Agent runtime integrations / Agent Runtime 集成

## Contribution principles / 贡献原则

1. Do not present invented facts as evidence. / 不得把编造的信息当作证据。
2. Separate observed facts, reported claims, inference, and assumptions. / 区分观察事实、他人陈述、推断与假设。
3. Prefer reusable reasoning patterns over one-off advice. / 优先贡献可复用的推理模式，而不是一次性建议。
4. New behavior should include an evaluation case where practical. / 新增行为尽可能配套评测案例。
5. Keep the core Skill concise; move detailed knowledge into references. / 保持核心 Skill 简洁，把详细知识放入 references。

## Pull requests / PR

Please explain:

- What changed / 改了什么
- Why it matters / 为什么重要
- Which behavior changes / Agent 行为如何变化
- How it was evaluated / 如何验证
- Known limitations / 已知限制
