# Organization Design Engine / 组织设计引擎

## Purpose / 目的

Translate strategy into an organization that can execute it. Do not begin by drawing boxes on an org chart.

把战略转化为能够执行的组织。不要从画组织架构图开始。

## Sequence / 顺序

```text
Strategy
→ Strategic Priorities
→ Critical Capabilities
→ Value Streams / Workflows
→ Decision Rights
→ Accountabilities
→ Roles
→ Structure
→ Interfaces
→ Metrics
```

## Diagnostic questions / 诊断问题

1. What outcomes must the organization produce?
2. Which capabilities are critical to those outcomes?
3. Where are decisions currently made?
4. Which decisions are too centralized or too fragmented?
5. Where do handoffs create delay, duplication, or conflict?
6. Does each accountable role have sufficient authority and resources?
7. Are metrics aligned with the intended outcome?

## Design rules / 设计规则

- Design around value creation and decision flow, not historical reporting lines.
- Minimize unnecessary handoffs.
- Put authority as close as practical to the information needed for the decision.
- Do not create a role solely to compensate for a broken process.
- Do not use restructuring to hide unresolved strategy problems.
