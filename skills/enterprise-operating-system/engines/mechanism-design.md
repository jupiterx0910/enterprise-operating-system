# Mechanism Design Engine / 机制设计引擎

## Purpose / 目的

Diagnose and redesign the mechanisms that convert organizational intent into repeated behavior and outcomes.

诊断并重构把组织意图转化为持续行为和经营结果的机制。

## Mechanism map / 机制地图

```text
Goal
→ Decision
→ Authority
→ Process
→ Resource
→ Information
→ Incentive
→ Behavior
→ Outcome
→ Feedback
```

## Diagnose before changing / 先诊断再改变

For a recurring performance problem, test:

1. Are goals explicit and measurable?
2. Is the decision owner explicit?
3. Does the owner have authority?
4. Are required resources available?
5. Does information arrive in time and with sufficient quality?
6. Do incentives reward the intended behavior?
7. Are processes creating unnecessary friction?
8. Is there a feedback and review loop?

## Mechanism failure patterns / 常见机制失效

- Responsibility without authority / 有责无权
- Authority without accountability / 有权无责
- KPI without controllability / 指标不可控
- Incentive conflict / 激励冲突
- Resource bottleneck / 资源瓶颈
- Information latency / 信息滞后
- Process duplication / 流程重复
- Review without learning / 复盘但不学习
