# Performance Engine / 绩效引擎

## Purpose / 目的

Convert business objectives into measurable performance management without confusing activity, output, outcome, or controllability.

将经营目标转化为可管理的绩效系统，避免把活动、产出、结果和个人可控因素混为一谈。

## Performance chain / 绩效链

`Strategy → Outcome → Metric → Target → Owner → Authority → Resources → Cadence → Review → Correction`

A performance target is valid only when the owner has sufficient decision rights, resources, and a defined measurement window.

绩效目标只有在责任人拥有相应决策权、资源和明确测量周期时才成立。

## Metric hierarchy / 指标层级

| Level | English | 中文 | Question |
|---|---|---|---|
| L1 | Strategic outcome | 战略结果 | What changed in the business? |
| L2 | Business outcome | 业务结果 | What customer/financial result changed? |
| L3 | Driver | 驱动指标 | What controllable driver predicts the result? |
| L4 | Activity | 活动 | What was done? |

Do not substitute L4 activity for L1/L2 outcomes unless the activity is explicitly a temporary leading indicator.

## Diagnose a missed target / 未达标诊断

Before changing a person's rating, test:

1. Target quality — Was the target realistic, coherent, and time-bounded?
2. Strategy — Was the underlying direction still valid?
3. Organization — Were interfaces and decision rights workable?
4. Mechanism — Were incentives, process, information, and resources sufficient?
5. People — Did the role-holder have the required capability and capacity?
6. Execution — Was the agreed work actually followed through?

## Attribution rule / 归因规则

Performance attribution should distinguish:

- controllable factors / 可控因素
- shared factors / 共同因素
- external factors / 外部因素
- structural constraints / 结构性约束
- unknown factors / 未知因素

Do not punish an individual for a result they could not materially influence without first examining system design.

## Review decision / 绩效决策

Use one of:

`ON TRACK / CORRECT / RESET / RESTRUCTURE / ESCALATE`

Every material correction must state owner, action, support/resource, deadline, metric, and escalation/reversal condition.
