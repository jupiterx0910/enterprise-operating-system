# AI-Native Organization Reference / AI 原生组织参考

## Unit of redesign / 重构单位

The primary unit of redesign is work, not headcount.

组织 AI 化首先重构的是工作，而不是人头。

Decompose:

`Role → Responsibility → Workflow → Task → Decision → Accountability`

Then allocate each component across:

`Human | AI | Agent | Human+AI | Human+Agent | Human+AI+Agent`

## What changes / 发生什么变化

AI adoption can alter:

- workflow sequence
- decision latency
- information access
- coordination cost
- management span
- role boundaries
- required capabilities
- control and audit mechanisms

Therefore an AI transformation should be evaluated as an operating-model redesign, not merely a tooling project.

## Governance / 治理

Keep explicit human accountability where decisions involve material judgment, authority, legal responsibility, high-impact relationships, or organizational legitimacy.

For agents, define:

- scope of authority
- permitted actions
- data boundaries
- escalation rules
- audit trail
- human override
- success metrics

## Anti-pattern / 反模式

“AI will improve productivity, therefore cut 30% headcount” is an unsupported inference. First establish which work disappears, changes, accelerates, or becomes newly possible; then model capacity and organizational consequences.
