# MBR Reference / 经营月度复盘参考

## Operating principle / 经营原则

The purpose of MBR is not to explain the past at length. It is to make the few decisions that improve the next operating period.

经营月度复盘不是长篇解释过去，而是做出少数能改善下一周期经营结果的关键决策。

## Standard dashboard / 标准看板

Track only metrics tied to current strategic priorities. A useful dashboard separates:

- outcome metrics
- leading drivers
- commitments
- unresolved blockers
- decisions pending

## Meeting design / 会议设计

Recommended flow:

`5 min context → 15 min results/gaps → 25 min diagnosis → 25 min decisions → 10 min commitments → 5 min review of prior actions`

The exact timing can change; the invariant is that discussion should end in decisions and owned actions.

## Decision hygiene / 决策卫生

Every repeated issue should eventually produce one of three outcomes:

- change the strategy
- change the operating system
- explicitly accept the constraint

Do not let recurring issues remain permanently in the reporting layer.
