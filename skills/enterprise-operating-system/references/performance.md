# Performance Reference / 绩效参考

## Core distinction / 核心区分

Performance management is a control-and-learning system, not a yearly scoring ritual.

绩效管理是控制与学习系统，而不是年度打分仪式。

Use four layers:

1. Outcome — business/customer/financial result.
2. Driver — leading variable with meaningful causal relevance.
3. Output — deliverable produced by a role or team.
4. Activity — work performed.

A mature system connects all four but does not confuse them.

## Target quality checklist / 目标质量检查

A target should have:

- clear business purpose
- measurable definition
- time window
- owner
- sufficient authority
- sufficient resources
- known dependencies
- review cadence
- explicit reset criteria

## Rating discipline / 评价纪律

When a result is below target, do not infer low capability automatically. Test target validity, external conditions, system constraints, execution quality, and role capability separately.

When a result exceeds target, do not infer leadership potential automatically. Test whether the person can operate at the scope, ambiguity, decision complexity, and stakeholder demands of the target role.
