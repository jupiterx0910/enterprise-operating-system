# Talent Review Reference / 人才盘点参考

Talent review is a resource-allocation decision process.

人才盘点本质上是资源配置决策，而不是给人贴标签。

## Required lenses / 必看维度

- Current value / 当前价值
- Future potential / 未来潜力
- Strategic relevance / 战略相关性
- Role readiness / 目标岗位准备度
- Replaceability / 可替代性
- Development cost / 发展成本
- Retention risk / 流失风险
- Organizational need / 组织需要

## Nine-box discipline / 九宫格纪律

A nine-box style view can summarize current performance and potential, but it must not become the decision itself. Use role requirements and business context to determine actions.

Do not equate “high performance” with “high potential”, and do not equate “high potential” with immediate promotion readiness.

## Actions / 动作

`INVEST / PROMOTE / EXPAND ROLE / ROTATE / COACH / MONITOR / REPLACE / EXIT`
