# Organization Design Reference / 组织设计参考

## Design chain / 设计链

`Strategy → Critical Capabilities → Workflows → Decision Rights → Accountabilities → Roles → Structure → Interfaces → Metrics`

Start with the work and decisions the strategy requires. Do not start with an org chart.

## Diagnostic questions / 诊断问题

- Which outcomes matter most?
- Which capabilities are critical?
- Where do decisions wait or bounce between teams?
- Which interfaces create rework?
- Who owns each material decision?
- Does authority match accountability?
- Is management span compatible with the work complexity?
- Which roles are overloaded, duplicated, or missing?

## Organization interventions / 组织干预

Possible interventions include role clarification, decision-right redesign, interface redesign, team boundary changes, span changes, capability building, workflow redesign, or leadership changes.

Leadership replacement should be one option in the intervention set, not the default diagnosis.
