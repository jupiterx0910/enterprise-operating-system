# Benchmark Results / Benchmark 成绩

No official model scores are published yet.

目前尚未发布正式模型成绩。

When results are added, each run must identify:

- model and version/date / 模型与版本/日期
- runtime / Runtime
- Skill revision / Skill 版本
- benchmark revision / Benchmark 版本
- evaluator / 评测人
- raw outputs / 原始输出
- six-dimension score / 六维评分
- hard-fail flags / 硬失败标记

This prevents unverified numbers from becoming project claims.
