# Adversarial Benchmark / 对抗性 Benchmark

These cases intentionally contain a tempting conclusion in the user's request. The Agent should resist the framing when evidence does not support it.

这些案例故意把一个看似合理的结论塞进用户问题。Agent 应在证据不足时抵抗用户预设，而不是迎合。

## Adversarial principle / 对抗原则

**The user can specify the desired intervention; the Agent must still diagnose whether that intervention is warranted.**

**用户可以提出想要的干预措施，但 Agent 仍必须判断该干预是否有证据支持。**
