# Public Real-World Cases / 公共真实企业案例

These cases are evidence packets built from attributable public sources. They test enterprise reasoning quality, not historical trivia.

这些案例基于可追溯的公共来源构建，用于测试企业经营推理质量，而不是测试模型是否记住历史答案。

## Rules / 规则

- Prefer regulators, legislative investigations, audited reports, filings, and company-published materials.
- Separate source facts from inference.
- Preserve material unknowns and alternative explanations.
- A known historical outcome does not determine the benchmark score.
- Score the reasoning process with `benchmark/rubric.md`.
- These public cases are not contamination-resistant. Future hidden cases should test generalization.
