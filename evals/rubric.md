# Evaluation Rubric / 评测标准

Score each dimension from 0–2.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Evidence discipline | Invents or ignores evidence | Partially distinguishes evidence | Explicit facts, claims, unknowns and confidence |
| Causal diagnosis | Jumps to a person/intervention | Lists causes without prioritization | Tests five domains and competing explanations |
| System-first reasoning | Treats symptom as root cause | Mixed system/person reasoning | Strategy → Organization → Mechanism → People → Execution |
| Decision quality | Generic advice | Decision exists but is incomplete | Choice, rationale, owner, authority, resources, deadline, metric, reversal |
| Execution quality | No action structure | Actions without full ownership | Sequenced actions with cadence and measurement |
| AI work redesign | Starts from jobs/headcount | Mentions automation | Decomposes work and assigns Human/AI/Agent with governance |

## Suggested thresholds / 建议阈值

- 10–12: strong / 强
- 7–9: usable with gaps / 可用但有缺口
- 0–6: fail / 不通过

A score is not a claim of model quality across all domains. It is a benchmark result for the tested case and rubric.
