# EOS Skill-Lift Leaderboard / EOS Skill 增益榜

> **No verified submissions yet. / 当前尚无 Verified 实跑结果。**

This leaderboard measures both model capability and the incremental effect of loading Enterprise Operating System.

这个榜单同时衡量模型能力，以及安装 Enterprise Operating System 后带来的增量效果。

## Primary ranking / 主排序

Verified entries are ranked by:

1. **Skill Lift** = EOS-enabled mean score − Native mean score
2. **Hard-Fail Reduction** = Native hard-fail rate − EOS-enabled hard-fail rate
3. EOS-enabled mean score

## Why not rank only by model score? / 为什么不只排模型分数

A raw model score mixes model capability, reasoning mode, system prompt, tools, and runtime. A paired experiment holds those variables as constant as possible and isolates the contribution of the EOS Skill.
