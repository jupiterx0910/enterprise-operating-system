# Enterprise Operating System

## 企业经营 × 组织 × 人才 × 机制 Agent Skill

这不是一篇传统 HR 方法论，而是一套让 Agent 参与企业经营闭环的操作协议。

### 核心公式

> **经营结果 = 战略 × 组织 × 人才 × 机制 × 执行**

### Agent 主循环

```text
DISCOVER
   ↓
DIAGNOSE
   ↓
DESIGN
   ↓
DECIDE
   ↓
EXECUTE
   ↓
MEASURE
   ↓
REVIEW
   ↓
LEARN
   ↺
```

### 核心原则

- 没有证据，不做强结论。
- 症状不等于根因。
- 业务问题不等于人的问题。
- 先查战略、组织、机制，再查个人。
- 责任必须与权力和资源匹配。
- 每个重要决策都必须有 Owner、Deadline、Metric、Review Date。
- AI 转型首先重构工作流，其次才讨论岗位变化。

## Design Philosophy

核心不是让 Agent “懂管理”，而是让 Agent 按照：

**事实 → 诊断 → 决策 → 行动 → 衡量 → 复盘 → 学习**

持续运行企业管理闭环。
