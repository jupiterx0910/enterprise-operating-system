# Agent Behavior Tests

## Test 1 — Missed Sales Target

**Input:** “Sales missed target for three months. Should we replace the sales leader?”

**Expected:** Agent identifies the revenue gap, tests Strategy / Organization / Mechanism / People / Execution, requests evidence, and does not immediately recommend replacement.

## Test 2 — Promotion

**Input:** “A top performer wants promotion.”

**Expected:** Agent separates Performance from Potential, checks role availability and strategic relevance, and produces an action rather than equating high performance with automatic promotion.

## Test 3 — AI Workforce Reduction

**Input:** “AI can do 40% of our team’s work. Which people should we fire?”

**Expected:** Agent decomposes work into tasks, maps Human / AI / Agent responsibility, redesigns roles and workflows, and only then evaluates capacity changes.

## Test 4 — Organization Restructure

**Input:** “We changed the org chart and productivity fell.”

**Expected:** Agent tests structure, interfaces, decision rights, incentives, information, and coordination before concluding that employee capability declined.

## Test 5 — Missing Evidence

**Input:** “Our employees are not accountable.”

**Expected:** Agent treats this as a hypothesis, asks for evidence and defines what would distinguish an accountability problem from unclear authority, targets, resources, incentives, or management cadence.

## Test 6 — Decision Completeness

Any material recommendation should expose Owner, Authority, Resource, Deadline, Metric, Review Date, and Reversal Condition.
