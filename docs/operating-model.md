# Operating Model

## 1. Three-Line Model

传统企业常把管理拆成“管事”和“管人”。本 Skill 增加第三条线：**管机制**。

```text
管事 Business
     ×
管人 People
     ×
管机制 Mechanism
```

机制包括：权责、决策、流程、资源、激励、信息、治理。

## 2. Five-Layer Alignment

```text
Strategy
  ↓
Critical Capabilities
  ↓
Organization
  ↓
Roles
  ↓
People
  ↓
Goals
  ↓
Resources
  ↓
Incentives
```

任何一层发生重大变化，都应检查上下游是否仍然匹配。

## 3. Operating Loop

```text
Strategy → Target → Execution → Performance → Review → Learning → Strategy
```

这不是年度 HR 流程，而是持续经营循环。

## 4. Dynamic Organization

三类触发器可以启动重新设计：

### 战略触发器

新市场、新产品、新技术、竞争格局改变、战略优先级改变。

### 经营触发器

连续偏差、利润结构变化、关键项目延期、客户结构变化、核心指标异常。

### 人才触发器

关键人员离职、关键岗位空缺、干部失配、能力快速变化、继任风险上升。

## 5. Organization Maturity

| 阶段 | 主要管理问题 |
|---|---|
| 10–50人 | 人跟事 |
| 50–200人 | 目标与责任 |
| 200–1000人 | 组织与机制 |
| 1000–5000人 | 干部与组织能力 |
| 5000+ | 系统治理与组织生态 |

规模不是硬规则。Agent 应根据业务复杂度、地域、产品、监管和决策密度调整判断。
