# Operating Model / 经营模型

## 1. Three-Line Model / 三线模型

Traditional management often separates “managing work” and “managing people”. This Skill adds a third line: **mechanism**.

传统管理常把“管事”和“管人”分开。本 Skill 增加第三条线：**管机制**。

```text
Business / 管事
      ×
People / 管人
      ×
Mechanism / 管机制
```

Mechanisms include decision rights, accountability, process, resources, incentives, information, and governance.

机制包括决策权、责任、流程、资源、激励、信息与治理。

## 2. Five-Layer Alignment / 五层映射

```text
Strategy / 战略
   ↓
Critical Capabilities / 关键能力
   ↓
Organization / 组织
   ↓
Roles / 岗位
   ↓
People / 人才
   ↓
Goals / 目标
   ↓
Resources / 资源
   ↓
Incentives / 激励
```

When one layer changes materially, inspect whether adjacent layers still fit.

任何一层发生重大变化，都应检查上下游是否仍然匹配。

## 3. Operating Loop / 经营循环

`Strategy → Target → Execution → Performance → Review → Learning → Strategy`

`战略 → 目标 → 执行 → 绩效 → 复盘 → 学习 → 战略`

This is a continuous operating cycle, not an annual HR process.

这是持续经营循环，而不是年度 HR 流程。

## 4. Dynamic Organization / 动态组织

Three trigger classes can start redesign.

三类触发器可以启动组织重新设计。

### Strategic Triggers / 战略触发器

New market, new product, new technology, competitive shifts, or changed priorities.

新市场、新产品、新技术、竞争格局变化或战略优先级变化。

### Operating Triggers / 经营触发器

Persistent performance gaps, profit-structure changes, delayed critical projects, customer-mix changes, or abnormal core metrics.

持续经营偏差、利润结构变化、关键项目延期、客户结构变化或核心指标异常。

### Talent Triggers / 人才触发器

Critical departures, vacant key roles, leadership mismatch, rapid capability shifts, or rising succession risk.

关键人员离职、关键岗位空缺、干部失配、能力快速变化或继任风险上升。

## 5. Organization Maturity / 组织成熟度

| Stage / 阶段 | Typical management focus / 主要管理重点 |
|---|---|
| 10–50 people / 10–50人 | People follow the work / 人跟事 |
| 50–200 / 50–200人 | Goals and accountability / 目标与责任 |
| 200–1,000 / 200–1000人 | Organization and mechanisms / 组织与机制 |
| 1,000–5,000 / 1000–5000人 | Leaders and organizational capability / 干部与组织能力 |
| 5,000+ / 5000+ | System governance and organizational ecosystem / 系统治理与组织生态 |

Headcount is not a hard rule. The Agent should adjust for business complexity, geography, product structure, regulation, and decision density.

人数只是参考，不是硬规则。Agent 应根据业务复杂度、地域、产品、监管和决策密度调整判断。
